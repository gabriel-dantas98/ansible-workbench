## Problemas do snapshot anterior

- `site.yml:3-4` forçava localhost/local; `group_vars/all.yml:2-3` usava HOME/USER do controlador; `ansible.cfg:5` desativava identidade SSH.
- `roles/base/tasks/main.yml:2-4` tratava não-Darwin como APT; `roles/base/tasks/linux.yml:64` instalava Hyper até no servidor.
- `roles/shell/tasks/linux.yml:43` sobrescrevia .zshrc; template linha 68 tinha teste SDKMAN malformado.
- `roles/version_managers/tasks/main.yml:19` clonava ASDF 0.16.5 sem instalar seu binário Go. Gerenciadores existiam sem runtimes.
- Variáveis Go 1.22.2, Terraform 1.13.5, Helm 3.17.2 e Ruby 2.6.10 não convergiam instalações. Linux fixava kubectl 1.34.0, k9s 0.50.4, kind 0.23.0; Codex 0.80.0.
- `roles/editors/tasks/linux.yml:108` usava TLS inseguro e URL não verificada; diversos erros eram ignorados.
- `roles/validation/tasks/main.yml:6` exigia Brew/Colima no Linux, dependia de PATH e só testava presença.

Essas referências são do snapshot auditado, não dos arquivos refatorados deste PR. As variáveis/aliases corporativos antigos foram removidos da configuração futura, sem repetir valores nem reescrever histórico Git.

## Escopo entregue versus próximo ciclo

Entregue: perfis, target remoto explícito, Ubuntu headless, complemento Arch/Omarchy, seleção macOS preservada, pacotes assinados, validação funcional e always-on. Removidos instaladores de procedência incerta, versões mortas e venv rastreado específico de outra máquina.

Próximo ciclo após hardware/acesso: GPU, runtimes por projeto, ferramentas cloud/IA adicionais, serviços de homelab, firewall com portas definidas, backups/monitoramento, seleção de extensões e dotfiles pessoais. Não há dados suficientes para inventar drivers GPU ou endereços SSH.

Na implementação, Docker daemon local estava desligado e disco tinha ~2,4 GiB livres: nenhum download de imagem ou instalação no Mac; containers previstos nos runners CI.

Atualização de direção após auditoria: o usuário escolheu Omarchy para AMBAS as máquinas. O inventário segue essa escolha; Ubuntu Server permanece alternativa testada. As recomendações originais não implicam suitability garantida sem especificações de hardware.
